# For Deee 💗 — 18-Slide Birthday Website

A small, personalized birthday website for Deee's 19th birthday, made with HTML, CSS, and JavaScript.

## What's included

- **18 sequential message slides** with a mix of affection, humour, memories, and reassurance.
- A welcome screen to open the surprise.
- Previous/Next navigation, a slide counter, and a progress bar.
- A final slide that lets the visitor start the experience again.
- Responsive styling for modern phone and desktop browsers.

## Files

- `index.html` — page structure and welcome screen.
- `style.css` — colours, typography, layout, and animations.
- `script.js` — all 18 messages and slide navigation.

## Run the website

1. Extract all files from this ZIP into one folder.
2. Keep `index.html`, `style.css`, and `script.js` together in that folder.
3. Open `index.html` in a modern browser.
4. Select **Open your surprise**, then use the arrows and **Next** button to read the slides.

No build step or server is required for the basic website. An internet connection may be needed to load the web fonts imported by the stylesheet; otherwise, the browser will use fallback fonts.

## Editing

- To change the messages or slide titles, edit the `slides` array near the top of `script.js`.
- To adjust the appearance, edit `style.css`.
- To change the welcome screen or page structure, edit `index.html`.
- If you add or remove slides, keep the displayed slide count in `index.html` and `script.js` in sync.

This version contains 18 text slides and does not include a separate photo-gallery slide.
